Where the record lives

The authoritative record is kept in the vault, not on this site — a transcript should not depend on a web page staying up. This page exists so a parent can see what is being tracked without installing anything.

  1. Mastery & Progress — per-lesson, marked Emerging / Proficient / Mastered, from the checkpoint and the evidence log rather than a single test score.
  2. Portfolio — the build artifacts. Photographs of the string-line lab, the measured angles, the clinometer, the capstone.
  3. Transcript — the semester and year record toward 1.0 Geometry credit.
  4. Inbox — where Stephen’s downloaded practice arrives, read before each session.

Twenty weeks, thirty Math-U-See lessons, forty sessions. Full coverage; nothing dropped to fit the calendar.
